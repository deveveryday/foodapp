# ReactJS FrontEnd - Teste Técnico — Desenvolvedor(a) Plataforma de Delivery


Este teste simula o tipo de trabalho do dia a dia: manutenção de um sistema real, corrigir bugs que aparecem em produção e implementar features novas.

---

## Setup

Requisitos mínimos

Node.js >= 18.x

```bash
npm install
npm run dev
```

Acesse `http://localhost:3000`.

---


## Entrega

1. Faça um **clone** deste repositório
2. Crie um repositório público no seu GitHub
3. Suba o seu código para esse repositório
4. Envie o link do projeto do seu GitHub para **[inserir e-mail]**


Boa sorte! 🚀
